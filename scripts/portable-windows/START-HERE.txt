美容仪线索工作台 | Windows x64 便携版

1. 把 ZIP 完整解压到有写入权限的本地文件夹。
2. 双击 Start-Workbench.cmd。规则筛选和 WhatsApp 模拟发送可以离线使用。
   浏览器未自动打开时，将启动窗口打印的 Workbench 地址完整粘贴到这台电脑的浏览器地址栏，保留 http://。端口以窗口打印为准。
3. 需要语义筛选时，先在原启动窗口按 Ctrl+C，再双击 Start-DeepSeek.cmd，按提示输入自己的 DeepSeek API Key。
4. 可在工作台导入本目录的 sample-leads.json。语义版可分析这批匹配许可清单的合成简介，提交分析后在工作台切到 DeepSeek 模式。
5. 工作台运行期间保持启动窗口打开。按 Ctrl+C 停止两个服务。H2 数据保存在 data 目录。退出后可复制该目录备份。

便携包包含所需 Java、Python 和应用依赖。目标 Windows x64 电脑使用系统自带的 Windows PowerShell。
语义筛选需要网络。发送流程使用 WhatsApp Mock。
